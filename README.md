# React Hero UI Portfolio Website

A modern, fully responsive portfolio website built with React, TypeScript, Hero UI, and Tailwind CSS.

## 🎨 Features

- **Modern Design**: Built with Hero UI components and Tailwind CSS
- **Responsive**: Fully responsive design for all screen sizes
- **TypeScript**: Full TypeScript support for type safety
- **Vite**: Lightning-fast build tool for development
- **Hero UI Components**: Beautiful, accessible UI components
- **Smooth Animations**: Smooth scrolling and transitions
- **Dark Theme**: Professional dark theme with gradient background
- **Icon Integration**: Lucide React icons for clean, scalable icons

## 📦 Tech Stack

- **React 18**: Latest React features
- **TypeScript**: Type-safe JavaScript
- **Vite**: Next generation frontend tooling
- **Hero UI**: Modern React component library
- **Tailwind CSS**: Utility-first CSS framework
- **Framer Motion**: Smooth animations and transitions
- **Lucide React**: Beautiful icon set

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Start development server**
   ```bash
   npm run dev
   ```
   The site will be available at `http://localhost:5173`

3. **Build for production**
   ```bash
   npm run build
   ```

4. **Preview production build**
   ```bash
   npm run preview
   ```

## 🎯 Sections Included

1. **Navigation Bar**: Smooth navigation with Hero UI Navbar
2. **Hero Section**: Your introduction with profile image
3. **About**: Brief description of yourself and skills
4. **Projects**: Showcase your 4 featured projects with live demo and code links
5. **Contact**: Call-to-action with email and LinkedIn links
6. **Footer**: Copyright and attribution

## 🛠️ Customization

### Update Your Information
Edit `src/App.tsx` and update:
- Your name and title
- About section content
- Project details and links
- Contact email
- Social media links
- Profile image

### Modify Colors and Styling
- Edit `tailwind.config.js` for Tailwind customization
- Modify `src/index.css` for global styles
- Use Hero UI's theme system by updating component props

### Add More Projects
Duplicate the project card component in the Projects section and update details.
